# Security policy

`evidence-gate` is a small library maintained by one person. It reads and parses
documents you hand it (PDF, Word, text), so a document from a source you do not
trust is untrusted input. This library is not a sandbox.

## Supported versions

Only the latest release is supported.

## Reporting a vulnerability

Please report it privately instead of opening a public issue:

- use **Report a vulnerability** in this repository's Security tab; or
- write to maher@torsion-labs.com with "evidence-gate security" in the subject.

This is a one-person project: expect a reply within about a week, on a best-effort
basis. There is no bug bounty.
